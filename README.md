# Snake-game-Pr-paration-au-projet-professionnel-2

Projet de groupe — HENALLUX

## Structure

main/
    main.py          → point d'entrée
    controller.py    → communication avec le frontend
    model.py         → logique du jeu
    maps.py          → définition des cartes
    templates/       → HTML
    static/          → CSS et JavaScript

docs/                → documentation du projet
tests/               → tests
assets/              → ressources du jeu

## Lancement

Installer les dépendances :

pip install -r requirements.txt

Puis lancer :

python main/main.py

L'application est ensuite accessible depuis un navigateur.

## Documentation

Voir le dossier `docs/`.

## Répartition

- Analyste → spécifications, logique, API, documentation, tests/acceptance
- Backend → modèle, contrôleur, API, intégration
- Frontend → HTML, CSS, JavaScript
- Chef d'équipe → GitHub, organisation et intégration
